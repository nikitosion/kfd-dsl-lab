# Свой DSL

Постройте язык проверок HTTP-ответа и сохраните поведение десяти функций из `lesson09.legacy`. HTTP-сервер и сетевые запросы не нужны: ответ представлен значением `HttpResponse`.

Требуются JDK 25 и интернет для первой загрузки Gradle и зависимостей. Версии: Kotlin 2.4.10, Gradle 9.5.1, JUnit 6.1.3.

| Действие | Bash | PowerShell |
|---|---|---|
| Сборка | `bash ./gradlew build` | `.\gradlew.bat build` |
| Тесты | `bash ./gradlew :app:test` | `.\gradlew.bat :app:test` |

Команды выполняются из корня проекта. Начните с [условия и контракта проверок](docs/lesson09.md).
Исходники находятся в `app/src/main/kotlin/lesson09`, тесты — в `app/src/test/kotlin/lesson09`. DSL добавьте в пакет `lesson09.dsl`.

Для продолжения в существующем проекте скопируйте каталог `lesson09` из обоих деревьев исходников и файл `docs/lesson09.md`. Сохраните свои настройки сборки, wrapper, README и CI. Потребуются уже подключённые в занятии «Инженерный контур» зависимости тестирования.
